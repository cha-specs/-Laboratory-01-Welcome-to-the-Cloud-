# Reflection

This Linux Playground activity helped me understand the basic concepts of Linux system administration. I learned how to create a new user account, give the user sudo privileges, and access the account through the terminal. I also learned how to check important system information such as the Linux distribution, kernel version, CPU, memory, and available disk space.

Creating the folder structure and Markdown files also helped me practice organizing files using Linux commands. At first, some commands were unfamiliar, but after following the steps and checking the results, I became more comfortable using the terminal.

Overall, this activity improved my confidence in using Linux and taught me that understanding basic system commands is important for an IT student. I learned that the terminal can be a powerful tool for managing users, files, and system resources efficiently.
